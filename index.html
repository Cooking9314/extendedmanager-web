Все модули

Вход и регистрация

Пароли только в виде Argon2id-хешей и скрыты из логов. Лимбо с капчей на карте, кросс-серверные сессии для HUB и вход по адресу.

security/security_config.yml

Наказания и SID

Баны, мьюты, гаги и предупреждения со списками, областным скоупом и историей. SID связывает аккаунты по адресу и банит за мультиаккаунт.

SID_config.yml · punishments.yml

Чат и рассылка

Локальный и глобальный чат, анти-спам, форматы MiniMessage. У каждого сообщения рассылки свои заголовок, подвал и звук; в админ-чат пишет и консоль.

chat/chat_config.yml · broadcast.yml

Миры, спавны и /hub

Мульти-миры с выбором типа, точки спавна и переходы между серверами сети. BungeeCord и Waterfall из коробки, для Velocity — свой адаптер.

worlds_config.yml · command_config.yml

Оформление и NPC

Ники игроков, спрайты игры в любом тексте, разметка в наковальне, книге и на табличке, NPC с диалогами, MOTD с иконкой и серверные ссылки.

npc/npc_config.yml · text_config.yml

Перезапуск и API

Остановка по расписанию, командой /em restart и из приложения: отсчёт с предупреждениями, кики и сохранение миров. HTTP API с потоками событий.

utils/restart_config.yml · config.yml

Приложение управления

ExtendedManagerApp для Windows подключается к HTTP API плагина: живая консоль, игроки и их скины, аккаунты и SID, инвентарь, чтение базы и аналитика. Несколько серверов сети — в одном окне, ключ доступа плагин генерирует сам.

  • консоль и события
  • игроки и скины
  • SID
  • инвентарь
  • база данных
  • аналитика

Сборка и установка

Исходники собираются Maven на JDK 25; готовые JAR и доступ к репозиторию — по приглашению автора

Сервер и прокси

  1. Установите JDK 25 и Maven 3.9+.
  2. Запустите build.cmd в корне репозитория.
  3. Положите target/ExtendedManager-0.14.0.jar в plugins/ каждого сервера сети.
  4. Для Velocity добавьте velocity/target/ExtendedManager-Velocity-0.14.0.jar в plugins/ прокси.
  5. Включите нужные модули в config.yml и выполните /em reload.
build.cmd

:: либо вручную
set "JAVA_HOME=C:\Program Files\Java\jdk-25.0.4"
mvn clean package
mvn -f velocity\pom.xml clean package

Серверы на Paper 26.2

Отдельное дерево 26.2/ — тот же 0.14.0, собранный под paper-api 26.2: свои списки спрайтов и api-version: '26.2'. Модули, команды и настройки совпадают с основной сборкой.

26.2\build.cmd

:: готовый файл
26.2\target\ExtendedManager-0.14.0.jar
