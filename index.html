Открыть документацию

Вход и регистрация

Пароли только в виде Argon2id-хешей и скрыты из логов. Лимбо с капчей на карте, кросс-серверные сессии для HUB и вход по адресу.

В документацию

Наказания

Баны, мьюты, гаги и предупреждения со списками, областью действия и историей. Защита аккаунтов связывает адреса и банит за мультиаккаунт.

В документацию

Чат и рассылка

Локальный и глобальный чат, анти-спам, форматы MiniMessage. У каждого сообщения рассылки свои заголовок, подвал и звук; в админ-чат пишет и консоль, а @ник в строке работает как упоминание.

В документацию

Миры, спавны и /hub

Мульти-миры с выбором типа, точки спавна и переходы между серверами сети. BungeeCord и Waterfall из коробки, для Velocity есть свой адаптер.

В документацию

Оформление и NPC

Головы и скины игроков в текстах, спрайты игры в любом тексте, разметка в наковальне, книге и на табличке, NPC с диалогами, MOTD с иконкой и серверные ссылки.

В документацию

Перезапуск и API

Остановка по расписанию, командой /em restart и из приложения: отсчёт с предупреждениями, кики и сохранение миров. HTTP API с потоками событий.

В документацию

Discord-бот

Статус сервера, вход и выход игроков в канал, привязка аккаунтов и слеш-команды. Токен хранится в конфиге, бот включается одним ключом модуля.

В документацию

Приложение управления

Нативное приложение для Windows поверх HTTP API: живая консоль, игроки со скинами, аккаунты, инвентарь, чтение базы и аналитика всех серверов сети.

В документацию

Всё разбито на модули

Каждый модуль выключен по умолчанию и включается одним ключом, а новые правки вступают в силу без перезапуска сервера.

security

Регистрация, лимбо с капчей, пароли Argon2id, проверки адреса и подсетей, кросс-серверные сессии.

Ключи конфигурации

chat

Чаты и их форматы, анти-спам, рассылка по расписанию, админ-чат, сообщения входа, выхода и смерти.

Ключи конфигурации

motd

Своё описание и иконка 64×64, плейсхолдеры онлайна, версии и платформы.

Ключи конфигурации

npc

NPC с именем, скином, позой и диалогами; команды и сообщения по клику.

Ключи конфигурации

discord

Статус сервера, вход и выход игроков в канал, привязка аккаунтов и слеш-команды.

Ключи конфигурации

api

HTTP API на плоском TCP: игроки, аккаунты, скины, инвентарь, чтение базы, консоль и SSE-потоки. Ключ генерируется один раз, лежит в базе и показывается командой /em app key.

Приложение администратора

Extended Manager App

Нативное приложение для Windows поверх HTTP API плагина: живая консоль и поток событий, игроки со скинами, аккаунты, инвентарь, чтение базы и аналитика. Все серверы сети в одном окне, а ключ доступа плагин генерирует и хранит сам.

  • Консоль и событиялоги сервера и команды в реальном времени
  • Игроки и скиныпрофиль, инвентарь и аккаунты в один клик
  • Чтение базытаблицы плагина без SQL-клиента и веб-панелей
  • Аналитикаонлайн, наказания и активность по серверам
  • Вся сетьVelocity и BungeeCord: несколько серверов в одном окне
  • Свой ключ доступаплагин генерирует ключ и хранит его в базе
Windows 10 и 11, x64 работает по HTTP API без агента на сервере
