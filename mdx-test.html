Документация / Команды / Телепорты и спавны

/hub

Описание

Переход на hub-сервер сети; имя сервера берётся из command_config.yml, секция hub. Умеет переносить другого игрока, в том числе с другого сервера.

Переход /hub требует настроенного hub.server в command_config.yml.

Настройка

Синтаксис/hub [игрок]
Канал переходаBungeeCord, его же форвардит Velocity
/hub
/hub Steve

command_config.ymlcommands.hub и hubкак устроен блок

  hub:
    enable: true
    aliases: []
    cooldown:
      enable: false
      duration: 0
      bypass:
        name: "extendedmanager.command.hub.cooldown.bypass"
        type: "permission"

hub:
  server: "hub"
  require-login: true
  cooldown-seconds: 3
  message: true
enable
Включает команду. false отвечает сообщением command-disabled и убирает /hub из /em help и из автодополнения Tab.
aliases
Дополнительные имена: список вроде ["away"] вызывает /hub и по слову /away. Имена из plugin.yml работают всегда, а свои алиасы применяет сам плагин, поэтому хватает /em reload.
cooldown.enable
Включает задержку между запусками /hub одним игроком.
cooldown.duration
Сколько секунд ждать после запуска: 0 не ждать.
cooldown.bypass
Кто задержку пропускает. name это узел права, type: permission даёт проход по выданному праву, type: OP работает только у операторов сервера.
server
Имя сервера hub в конфигурации прокси: его берёт BungeeCord или Velocity, а не список миров на сервере. Пусто, и /hub отвечает, что переход не настроен.
require-login
Требовать вход по /login перед уходом в хаб: незалогиненный игрок остаётся на месте.
cooldown-seconds
Секунды между переходами одного игрока, 0 не ждать. Это своя пауза /hub, общий cooldown команды работает поверх неё.
message
Показывать ли игроку подтверждение перехода.

Права

extendedmanager.command.hubпо умолчанию у операторов

Доступ к команде /hub (переход на hub-сервер)

extendedmanager.command.hub.othersпо умолчанию у операторов

Перенос другим игрокам (/hub <игрок>)

extendedmanager.command.hub.cooldown.bypassвыдают вручную

Пропускает задержку cooldown команды /hub.

Документация / Команды / Осмотр и обмен

/trade

Описание

Безопасный обмен предметами через окно с подтверждением обеих сторон; кнопки принятия и отказа прямо в окне.

Предметы обеих сторон на время сделки лежат в памяти плагина, а не в окне:

  • обмен совершается, только когда подтвердили обе стороны;
  • любая правка предложения снимает оба подтверждения;
  • закрытое окно, выход или смерть игрока отменяют сделку и возвращают предметы владельцам.

Обмен возможен только между игроками в сети и не дальше trade.distance-blocks.

Настройка

Синтаксис/trade <игрок>
accept, denyПринять или отклонить входящее предложение
cancelОтменить своё предложение
Без аргументовВозвращает открытое окно обмена
/trade Steve
/trade accept
/trade cancel

command_config.ymlcommands.trade и tradeкак устроен блок

  trade:
    enable: true
    aliases: []
    cooldown:
      enable: false
      duration: 0
      bypass:
        name: "extendedmanager.command.trade.cooldown.bypass"
        type: "permission"

trade:
  enabled: true
  distance-blocks: 10
  request-expire-seconds: 60
  slots-per-side: 16
  log: true
  blocked-materials: []

Границы сделки

Размер окна и расстояние задаёт секция trade, а не блок команды: правка применяется после /em reload, перезапуск сервера не нужен.

enable
Включает команду. false отвечает сообщением command-disabled и убирает /trade из /em help и из автодополнения Tab.
aliases
Дополнительные имена: список вроде ["away"] вызывает /trade и по слову /away.
cooldown.enable
Включает задержку между запусками /trade одним игроком.
cooldown.duration
Сколько секунд ждать после запуска: 0 не ждать.
cooldown.bypass
Кто задержку пропускает. name это узел права, type: permission даёт проход по выданному праву, type: OP работает только у операторов сервера.
enabled
Разрешить обмен предметами.
distance-blocks
Как близко нужно встать, в блоках. 0 расстояние не проверять, тогда торговаться можно хоть через весь сервер.
request-expire-seconds
Сколько секунд ждать ответа на запрос обмена.
slots-per-side
Слотов на сторону: 4, 8, 12 или 16. Окно делится пополам: своя половина слева, чужая справа, над каждой стоит голова игрока.
log
Писать состоявшиеся сделки в консоль: кто, с кем и сколько предметов.
blocked-materials
Материалы, которые нельзя класть в сделку: имена Material без учёта регистра, например ["BEDROCK", "COMMAND_BLOCK"].

Права
