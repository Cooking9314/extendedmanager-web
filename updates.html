0.14.0 Актуальная 14 ноября 2026
  • безопасность
  • API
  • utils
  • Пароли игроков хешируются Argon2id; старые записи тихо обновляются при входе.
  • Ключ API генерируется один раз, хранится в базе и показывается командой /em api key; сверка по SHA3-512.
  • Модуль utils: перезапуск по расписанию, командой /em restart и из API — с предупреждениями и сохранением миров.
  • Защита аккаунтов банит за мультиаккаунт причиной Multiaccount.
  • У каждого сообщения рассылки свои заголовок, подвал и звук.
  • Консоль пишет в админ-чат через /say @текст.
  • command_config.yml вместо emcommand_config.yml.
  • Модуль anticheat удалён полностью.
0.13.1 14 ноября 2026
  • Velocity
  • сеть
  • Адаптер для Velocity: каналы extendedmanager:main и bungeecord:main, перенос присутствия и переходов между серверами.
  • На прокси переехали MOTD, Security и Discord-бот со своим config.yml и командой /velocity reload.
  • Присутствие уходит частями по 512 игроков — большой HUB больше не теряется в лимите plugin message.
  • /hub умеет переносить другого игрока с другого сервера.
